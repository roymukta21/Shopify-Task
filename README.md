# Raaya Social — Landing Page

Live site: [https://shopify-task-three.vercel.app/]



## About

This is a landing page I built for a frontend task. The design was given as a Figma file and I converted it into a fully responsive webpage using only HTML, CSS, and JavaScript.

No frameworks or libraries were used — everything is written from scratch.


## What's included

- Sticky navbar with mobile hamburger menu
- Hero section with animated video cards
- Auto-scrolling client logo strip
- Services section with interactive pricing selector
- Video carousels (drag to scroll)
- Client testimonials and reviews
- FAQ accordion
- Footer with contact form



## Tech

- HTML5
- CSS3 (Flexbox, Grid, custom properties, animations)
- Vanilla JavaScript


## Running locally

Clone the repo and open `index.html` in your browser. No build step needed.

```bash
git clone https://github.com/roymukta21/shopify-task.git
cd shopify-task
open index.html
```
